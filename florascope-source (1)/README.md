# FloraScope — drone dMRV for nature-based carbon

**FloraScope** (by Flora Carbon AI) turns a drone orthomosaic (plus an optional canopy-height or surface model) into an audit-ready, GPS-tagged tree inventory:

- individual tree detection with crown outlines, height and health
- survival vs planting design, stocking per hectare, gap cells and a replanting list
- biomass → tCO₂e (Jucker 2017 + Chave 2014 for ARR, Komiyama 2005 for mangroves) with Monte Carlo uncertainty and the VCS Methodology Requirements v5.0 §2.4 deduction
- QA plots (precision / recall / count correction), field-plot planner (GPX/CSV/GeoJSON), and field DBH/height calibration
- tree-level change between two flights (survival, mortality, growth, paired stock change)
- pre-audit readiness checks and a printable monitoring report with SHA-256 chain of custody

Everything runs **in the browser** (Web Worker). No server, no uploads — client imagery never leaves the analyst's machine.

> The two demo projects use **synthetic** imagery generated by `scripts/generate_demo_data.py`. Their benchmark scores are an upper bound; establish accuracy on real flights with QA and field plots.

## Quick preview on Netlify (no build)

1. Take the `out/` folder (or `florascope-netlify-drop.zip`).
2. Open <https://app.netlify.com/drop> and drag the folder (or the zip) onto the page.
3. Netlify gives you a live URL in seconds. Open `/workspace/?demo=arr` for the dryland ARR demo or `/workspace/?demo=mangrove` for the mangrove demo.

## Deploy from Git

```bash
npm install
npm run build      # static export -> out/
```

`netlify.toml` already sets `command = "npm run build"` and `publish = "out"`. Push the repo to GitHub and import it in Netlify.

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run bench      # detection benchmark on the demo data (Node)
npm run demo-data  # regenerate synthetic demo data (needs python3, numpy, scipy, rasterio, pyproj)
```

## Using your own data

- **Orthomosaic:** GeoTIFF (RGB, RGBA, or RGB+NIR; 8/16-bit or float), or JPG/PNG with a world file (`.jgw/.pgw`) and EPSG code. Exports from WebODM, Pix4D, Agisoft Metashape and DJI Terra work.
- **Height model (recommended):** CHM GeoTIFF (heights above ground), or a DSM GeoTIFF (FloraScope estimates the ground with a moving-minimum filter).
- Large rasters are downsampled to a working limit (default 16 MP, adjustable in the upload dialog).

Set the planting spacing, planted area and species mix (wood densities) in the sidebar; then validate with QA plots and field plots before reporting.

### Dense or mixed canopy (touching crowns)

When most of the image is continuous green (agroforestry, natural regeneration, palms among shrubs) the default crown-shape detector splits single trees into several. FloraScope shows a warning and offers **Calibrate crowns**:

1. In the Imagery tab choose **Calibrate** and drag from the centre of the **smallest** tree crown to its edge, then the **largest** one (add a few more typical crowns if you like).
2. Switch to **Not a tree** and mark 1–3 patches of grass / ground cover / soil.
3. Click **Apply & re-detect**. Detection switches to *Crown segments*: colour/texture superpixels merged into crown-sized regions bounded by your examples. *Crown merging* is automatic by default (matched to your example crowns) and can be set manually in the sidebar.
4. Use **Merge** to join pieces of one tree, and **Edit** to flag false trees or add missed ones.

## Project layout

```
src/lib/          detection (cv.ts, detect.ts), raster loading, allometry, carbon MC,
                  survival, QA, change, pre-audit, exports
src/workers/      compute worker (detection + Monte Carlo)
src/components/   workspace UI (viewer, map, tabs, report)
src/app/          landing page, /workspace, /methods
public/demo/      synthetic demo GeoTIFFs + ground truth
scripts/          demo-data generator and Node benchmarks
```

See `/methods` in the app for algorithms, equations, defaults, limitations and references.
